# Course-id changes — 2026-09-29 recompile

The 2026-09-29 Foundry recompile (real course names, recovered holes, node-facility fence)
changes the course-id list or the hole numbers of these facilities. A saved round on an
affected id can show different holes after a re-download.

- **added** — a course the old build dropped (un-numbered OSM hole ways, or a second course
  hidden inside one blob). Existing ids keep their position; new courses append as `#N`.
- **removed** — only on map-point (node) facilities: the old build copied a neighbouring
  course's holes into the point's pack. Those holes still ship in the neighbour's own pack.
- **split** — one id carried more than one course glued together (up to 54 holes); it now carries
  one course and the others move to new `#N` ids.
